Docente en Marcha

Descripción del proyecto

Docente en Marcha es un proyecto web desarrollado como parte del Proyecto Integrador de quinto semestre. Su objetivo es presentar una plataforma orientada a la gestión y el seguimiento de las prácticas docentes, con diferentes módulos según el tipo de usuario.

Objetivo

Desarrollar una interfaz web que permita organizar la información relacionada con estudiantes, docentes, instituciones educativas, prácticas y procesos de seguimiento.

Tecnologías utilizadas

- HTML5: estructura y contenido de las páginas web.
- CSS3: diseño, colores, distribución y estilos de la interfaz.
- JavaScript: funciones e interacciones de los diferentes módulos.

Estructura del proyecto

El proyecto está organizado en las siguientes carpetas:

- inicio: contiene la página principal y sus estilos.
- director: contiene las páginas del módulo del director, como estudiantes, docentes, instituciones, asignaciones, evaluaciones, indicadores y reportes.
- coordinador: contiene las páginas del módulo del coordinador, como estudiantes, docentes asesores, instituciones, grupos, prácticas, asignaciones y seguimiento.
- docente: contiene las páginas del módulo del docente, como estudiantes, perfil, evaluaciones, rúbricas, visitas y retroalimentaciones.
- estudiante: contiene las páginas del módulo del estudiante, como actividades, perfil, práctica, evaluaciones, evidencias y retroalimentaciones.
- imagenes: almacena los recursos gráficos utilizados en el proyecto.

Organización de los archivos

Cada módulo cuenta con archivos HTML para las páginas y archivos CSS para sus estilos. Los módulos de director, coordinador y docente también incluyen archivos JavaScript para manejar diferentes interacciones.

Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto en tu computador.
3. Ingresa a la carpeta inicio.
4. Abre el archivo index.html en un navegador web.
